
# 🤖 Chotu Clone

A web application built with Next.js, React, TypeScript, and Tailwind CSS.

---

## 📌 Overview

Chotu Clone is a frontend web project built using the Next.js framework. It uses a modern React-based architecture, TypeScript for type safety, and Tailwind CSS for styling.

The project provides a foundation for building and customizing a web interface with a modern development workflow.

## 🛠️ Tech Stack

- **Next.js 16** — React-based web framework
- **React 19** — Component-based user interfaces
- **TypeScript** — Static type checking
- **Tailwind CSS 4** — Utility-first styling
- **ESLint** — Code quality and linting

## ⚙️ Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git (optional)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/RasheedBShaik/chotu-clone.git
```

**2. Navigate to the project directory**

```bash
cd chotu-clone
```

**3. Install dependencies**

This project includes a pnpm lockfile, so pnpm is recommended.

```bash
pnpm install
```

**4. Start the development server**

```bash
pnpm dev
```

**5. Open the application**

Visit [http://localhost:3000](http://localhost:3000) in your browser.
